# Site Deployment Planner

## What Is This?

The Site Deployment Planner is a web application for organizing and tracking technology deployments across multiple locations. It provides a dashboard showing deployment sites, schedules, device counts, readiness information, progress, and current status. Users can filter deployments by status and search for specific sites or locations.

## Why Does It Exist?

I built this project around the type of site deployment work I encounter professionally. Technology deployments often involve multiple locations, different stages of preparation, equipment requirements, and schedules that need to be tracked at the same time. The purpose of this project is to provide a simple visual dashboard for organizing that information and quickly seeing the current state of each deployment.

This version represents the first major milestone of the project. Additional features and improvements can be added as the project continues.

## What Tools Did I Use?

- **HTML** - Used to create the structure and content of the web application.
- **CSS** - Used to create the dashboard layout, responsive design, typography, status indicators, cards, and visual styling.
- **JavaScript** - Used to create interactive status filtering and site search functionality.
- **Visual Studio Code** - Used as the primary editor for writing and managing the project files.
- **Git and GitHub** - Used for version control and storing the project repository.
- **GitHub Pages** - Used to deploy the project as a publicly accessible website.
- **ChatGPT** - Used as an AI assistant for troubleshooting, reviewing code, brainstorming interface improvements, and working through implementation decisions.
